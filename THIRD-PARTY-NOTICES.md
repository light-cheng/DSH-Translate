upstream datasets below. Every modification listed here is made by that script.

## Corresponding source for the GPL-3.0 data

The complete preferred form for modification is the build script plus the upstream inputs
it downloads:

- `scripts/build-dictionary.mjs` (shipped in this repository and in the package)
- https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
- https://raw.githubusercontent.com/open-dict-data/ipa-dict/master/data/en_US.txt
- https://raw.githubusercontent.com/open-dict-data/ipa-dict/master/data/en_UK.txt

`npm run build:dict` recreates `data/dictionary.json.gz` from those inputs (the script
caches them under `tmp/`, so it also works offline). The payload embeds its build date, so
the bytes match only when the rebuild happens on the same day; the content and the
selection rules are deterministic. No GPL-licensed data is combined into the plugin source
code: `data/` is loaded at runtime as a separate file, which is mere aggregation, so the
code stays MIT.

## Pronunciation audio

Word audio is requested at play time from Youdao's public `dictvoice` endpoint
(`https://dict.youdao.com/dictvoice`). No audio is bundled or redistributed; the word being
pronounced is the only thing sent, and only when the user clicks or hovers the button.
